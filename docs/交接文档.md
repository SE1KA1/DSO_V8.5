## 3. 硬件与资源

| 项目 | 说明 |
| --- | --- |
| MCU | STM32H743IIT6，400 MHz，I/D Cache 开启 |
| 外部 SDRAM | 32 MB @ `0xC0000000`（FMC） |
| 显示屏 | RGB 并行 + LTDC，物理 480×800 |
| 输入 | MCP23017 I2C IO 扩展：EC1/EC2 编码器 + 按键 |
| ADC 采样 | 8-bit 三路交替（默认）或 10-bit 双 lane + CH2 实时 |
| 外部测频 | PB15 / TIM12_CH2（默认占用，LED4 GPIO 关闭） |
| 波形发生器 | PA4 / DAC1（可选任务 `DSO_Wavegen_Task`） |
| 调试串口 | UART1，1152000 baud（VoFA/诊断同口） |

显存布局单一来源：`User/bsp/inc/bsp_vram_layout.h`  
SDRAM 应用区划分：`User/bsp/inc/bsp_sdram_layout.h`

## 4. 构建与烧录

### 4.1 Keil MDK（推荐）

1. 打开 `Project/MDK-ARM(uV5)/` 下 `.uvprojx` 工程  
2. 选择目标 `STM32H743IIT6`  
3. **Rebuild All** → **Download**  
4. 复位后 UART1 应出现 `[BOOT] UART1 direct OK`（若 `DSO_APP_INFO_PRINTF_ENABLE=1` 还有更多 `[BOOT]` 行）

### 4.2 关键编译宏（Preprocessor）

| 宏 | 默认 | 作用 |
| --- | --- | --- |
| `USE_DSO_ENGINE` | 1 | 1=真实 DSO 引擎；0=假波形任务 |
| `DSO_APP_INFO_PRINTF_ENABLE` | 0 | 1=打开 [BOOT]/[APP] 等信息 printf |
| `UI_APP_DEMO_CYCLE_SCREENS` | 1 | 1=多页 Demo；0=仅示波器循环 |
| `UI_LIGHT_PATH_RELAX` | 0 | 1=PlotBuf 初始化失败时不 Error_Handler |

## 5. 运行时架构

### 5.1 FreeRTOS 任务

| 任务名 | 优先级 | 栈(words) | 周期/职责 |
| --- | ---: | ---: | --- |
| `emWin` (MainTask) | 2 | 14336 | UI 主循环；RUN 25 ms 定帧绘制 |
| `DSOEng` | 1 | 10240 | 采集/处理/发帧；~1 ms 服务环 |
| `ecpoll` | 3 | 2048 | EC1/EC2 轮询 8 ms |
| `Wavegen`（可选） | 2 | 2048 | PA4 DAC 波形输出 |

创建位置：`User/main.c`  
详细时序：`docs/architecture/02-runtime-task-flow.md`

### 5.2 数据流（简图）

```
ADC/TIM/DMA → DSO_Engine_Task → DSO_Frame
                    ↓ DSO_UI_SendFrame
              UI_WaveformCtrl（2-slot 帧环）
                    ↓ UI_Waveform_CopyUIFrame
              MainTask → PlotBuf/DMA2D → RenderLatch → LTDC
```

### 5.3 页面导航

- 欢迎 → 主菜单 → 示波器 / 通道 / 触发 / 测量 / 系统  
- 编码器路由：`User/ui/ui_nav.c`（文件头有各页 EC 映射摘要）  
- 示波器页波形由 `MainTask_Scope_RenderFrame()` 绘制，其它页由 `ui_screens.c`

## 9. 源码注释规范（交接后维护）

每个 `User/` 下新增或重大改动的 `.c`/`.h` **必须**在文件开头包含：

```c
/**
 * @file 文件名
 * @brief 一句话功能性说明（职责、线程、与谁交互）
 */
```

### 9.1 刷新注释索引

```bash
node tools/add_source_annotations.js          # 为缺少 @file 的文件补头
node tools/add_source_annotations.js --dry-run  # 预览
```

修改 `tools/file_annotations.json` 可覆盖核心文件的 `@brief` 文案；然后重新运行脚本并刷新索引：

```bash
node -e "/* 见 tools/add_source_annotations.js 内索引生成逻辑，或重新运行 docs 生成命令 */"
```

（索引生成命令见仓库 `tools/` 目录 README 或本文档历史版本。）
