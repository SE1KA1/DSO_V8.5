# STM32H743 移植说明

## 文件

协议层与 MCU 无关：

```text
include/fmc16_protocol.h
src/fmc16_protocol.c
```

STM32H743 端口层：

```text
include/fmc16_port_stm32h743.h
src/fmc16_port_stm32h743.c
```

完整 XO2 FMC 数据编解码：

```text
include/fmc16_full_board.h
src/fmc16_full_board.c
```

换 MCU 或换引脚时，保留协议层，重写端口层。

## 引脚

| 信号 | STM32H743 引脚 | AF |
|---|---|---:|
| D0 | PD14 | AF12 |
| D1 | PD15 | AF12 |
| D2 | PD0 | AF12 |
| D3 | PD1 | AF12 |
| D4-D12 | PE7-PE15 | AF12 |
| D13 | PD8 | AF12 |
| D14 | PD9 | AF12 |
| D15 | PD10 | AF12 |
| NE1 | PC7 | AF9 |
| NOE | PD4 | AF12 |
| NWE | PD5 | AF12 |

所有引脚使用 `GPIO_NOPULL`。NWAIT 和 FMC_CLK 不初始化。

PC7 的 FMC_NE1 使用 AF9，不是 AF12。

## 时钟

```text
SYSCLK     = 400 MHz
D1CPRE     = /4
FMC kernel = 100 MHz
```

端口初始化会检查 SYSCLK 和 D1CPRE。不符合时返回 `FMC16_STM32_ERR_CLOCK`。

## MPU

`0x60000000` 配置为 64 KiB：

```text
full access
execute-never
non-cacheable
non-bufferable
non-shareable
```

在系统时钟和基础 MPU 配置完成后调用：

```c
fmc16_stm32h743_mpu_config();
```

后续代码不要覆盖这个 MPU region。

## FMC

| 项目 | 配置 |
|---|---|
| Bank | Bank1 / NE1 |
| Memory type | SRAM |
| Data width | 16 bit |
| Address mux | Disabled |
| Burst | Disabled |
| NWAIT | Disabled |
| Extended mode | Enabled |
| Write | Enabled |
| Write FIFO | Disabled |
| Access mode | A |

时序寄存器：

```text
BTR1 / BTCR[1]                 = 读时序
BWTR1 / FMC_Bank1E_R->BWTR[0] = 写时序
BTCR[2]                        = BCR2
```

读写时序相同：

```text
ADDSET  = 4
ADDHLD  = 6
DATAST  = 255
BUSTURN = 10
CLKDIV  = 2
DATLAT  = 2
ACCMOD  = A
```

DATAST=255 对应约 2.55 μs。改小时需要重新测试读包、写命令和 CRC。

## 初始化

```c
#include "fmc16_port_stm32h743.h"

fmc16_stm32h743_mpu_config();

if (fmc16_stm32h743_init() != FMC16_STM32_OK) {
    /* 记录错误并停止通信。 */
}
```

返回值：

| 返回值 | 含义 |
|---|---|
| `FMC16_STM32_OK` | 初始化成功 |
| `FMC16_STM32_ERR_CLOCK` | 时钟配置不符 |
| `FMC16_STM32_ERR_HAL` | HAL FMC 初始化失败 |

## 字读写

端口层从同一地址访问 16-bit word：

```c
uint16_t word = *(volatile uint16_t *)0x60000000;
*(volatile uint16_t *)0x60000000 = word;
```

一个数据包要连续写完。使用 RTOS 或多个 FMC 设备时，在包级加互斥，避免其它访问插入包中间。

## 上电顺序

1. STM32 保持复位或共享引脚为高阻。
2. 烧录并复位 XO2。
3. 断开 XO2 JTAG。
4. 启动 STM32。
5. 运行 `fmc16_minimal_smoke_run_with_capabilities()`，保存对端能力字。

最小通信端返回 `0x00000003`，完整 XO2 FMC 端返回 `0x00002BF7`。两者使用相同的 FMC 引脚和基础数据包格式。接收端应检查异步读写能力是否齐全，不要要求能力字精确等于 `0x00000003`。

最小测试通过后，再按 `XO2FMC完整板数据对接.md` 接入业务数据。完整板代码不改变 FMC 引脚、MPU 或读写时序。
