# 模块 4：U10-INA226AIDGSR（过桥板电流监测）

## 1. 硬件与用途

| 项 | 值 |
|---|---|
| 器件 | INA226（U10，过桥板） |
| I2C 7 位地址 | **0x41**（SDA=PB7, SCL=PB8，同一条软件 I2C 总线） |
| 检流电阻 | 100mΩ（分流 LSB 2.5µV → 1 LSB = 0.025mA；cur_ma = lsb/40） |
| 固件 | dso_ina226.c：1s 采样（prio3），判级**纯分流阈值**（芯片 AFF 锁存不强制等级） |
| 用途 | 过桥板供电电流监测；参与声光联动（YDS1 红/YDS2 绿 + 蜂鸣器，见 02 总则） |

> 实测正常工作电流 10~23mA 波动。同型号第二颗 U44（0x40，20mΩ，核心板）见 05。

## 2. 周期上报 `type: module.data`（1s 周期）

```json
"data": {
  "cur_ma": 12,         // int  电流 mA（可负=反向；lsb/40 取整，分辨率 0.025mA）
  "over_cur": 0,        // int 0/1  过流（≥告警线 35mA 或芯片 AFF；恢复迟滞）
  "valid": 1,           // int 0/1  最近读成功（0=保留上次值，勿当真实 0mA）
  "level": 0            // int  声光联动分级：0正常 1预警 2告警 3紧急（见下）
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `cur_ma` | int | ✓ | mA，含符号 |
| `over_cur` | int | ✓ | 0/1；1=过流（`power_ok` 反，见下"判级与恢复"） |
| `valid` | int | ✓ | 0/1；0=通信失效（保留上次值，勿当真实 0mA） |
| `level` | int | ✓ | 分级见下表；读失败保留上次判定 |

**电流分级阈值**（宏见 `User/dso/dso_ina226.h`，额定 35mA=1400 LSB）：
| level | 语义 | 阈值（mA / LSB） | 硬件动作（按 02 总则） |
|---|---|---|---|
| 0 | 正常 | ≤29.75mA（1190 LSB，额定 85%） | YDS2 绿常亮；蜂鸣器静音 |
| 1 | 预警 | >29.75mA | YDS1 红慢闪 500/500ms；蜂鸣 250/1750ms |
| 2 | 告警 | >35mA（1400 LSB，额定 100%） | YDS1 红快闪 250/250ms；蜂鸣 250/250ms |
| 3 | 紧急 | >52.5mA（2100 LSB，额定 150%） | YDS1 红爆闪 100/100ms；蜂鸣 100/100ms |

**判级与恢复**：
- 等级仅按当前分流值比较阈值（AFF 只进 `over_cur`，不强制等级——芯片锁存残留不升紧急）。
- 过流恢复：降到 ≤ 恢复线（28mA = 告警线×4/5）且连续 3 个采样周期 → `over_cur` 回到 0。
- 蜂鸣器由节奏引擎驱动（写本芯片 ALERT_LIMIT 通断），等级取温度与两路电流最高档；可 `set_buzzer` 静音。

## 3. 事件 `type: module.event`

```json
"data": {"event": "overcurrent", "level": "warning", "detail": "cur 40mA > 35mA"}
{"event":"recovered"}、{"event":"comm_lost"}
```

| event | 触发 |
|---|---|
| `overcurrent` | `over_cur` 0→1 跳变 |
| `recovered` | `over_cur` 1→0 跳变（连续 3 周期 ≤ 恢复线确认） |
| `comm_lost` | 连续读失败（保留上次值） |

## 4. 示例完整帧

```json
{"ver":"1.0","type":"module.data","module":"ina226_u10","seq":20,"ts_ms":2100000,"data":{"cur_ma":12,"over_cur":0,"valid":1,"level":0}}
{"ver":"1.0","type":"module.event","module":"ina226_u10","seq":21,"ts_ms":2150000,"data":{"event":"overcurrent","level":"warning","detail":"cur 40mA > 35mA"}}
```

## 5. 后端解析要点
- 模块 id 用 `ina226_u10` 与核心板 `ina226_u44` 区分（同型号两颗）。
- 后端展示/告警统一用 `level`（0..3 分级），勿用 `cur_ma` 自行设阈值（固件阈值见上表，调整需固件宏同步）。
- `over_cur` 是布尔过流位（供简单红灯/弹窗），`level` 更细。
