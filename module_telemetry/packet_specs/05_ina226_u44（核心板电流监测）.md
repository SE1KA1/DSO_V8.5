# 模块 5：U44-INA226AIDGSR（核心板电流监测）

## 1. 硬件与用途

| 项 | 值 |
|---|---|
| 器件 | INA226（U44，核心板） |
| I2C 7 位地址 | **0x40**（SDA=PB7, SCL=PB8，同一条软件 I2C 总线） |
| 检流电阻 | **20mΩ**（分流 LSB 2.5µV → 1 LSB = 0.125mA；cur_ma = lsb/8） |
| 固件 | dso_ina226_u44.c：1s 采样（prio3），判级**纯分流阈值**（迟滞恢复 ×4/5） |
| 用途 | 核心板供电电流监测；与 U10 一起参与声光联动（红灯 YDS1 取两路最高级） |

> 实测核心板正常工作电流 118mA。与 U10（0x41/100mΩ）同型号第二实例，仅地址与检流电阻不同。

## 2. 周期上报 `type: module.data`（1s 周期）

```json
"data": {"cur_ma": 118, "over_cur": 0, "valid": 1, "level": 0}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `cur_ma` | int | ✓ | mA，含符号；**20mΩ 下 = lsb×0.125** |
| `over_cur` | int | ✓ | 0/1；1=≥告警线 160mA 或芯片 AFF |
| `valid` | int | ✓ | 0/1；0=通信失效（保留上次值） |
| `level` | int | ✓ | 分级见下表；读失败保留上次判定 |

**电流分级阈值**（宏见 `User/dso/dso_ina226_u44.h`，额定 160mA=1280 LSB）：
| level | 语义 | 阈值（mA / LSB） | 硬件动作（按 02 总则） |
|---|---|---|---|
| 0 | 正常 | ≤136mA（1088 LSB，额定 85%） | 绿灯亮；蜂鸣器静音 |
| 1 | 预警 | >136mA | 红灯慢闪 500/500ms（两路电流取最高级）；蜂鸣 250/1750ms |
| 2 | 告警 | >160mA（1280 LSB，额定 100%） | 红灯快闪 250/250ms；蜂鸣 250/250ms |
| 3 | 紧急 | >240mA（1920 LSB，额定 150%） | 红灯爆闪 100/100ms；蜂鸣 100/100ms |

> 红灯 YDS1 显示 U10 与 U44 两路电流的**最高等级**；判级与恢复规则同 04（恢复线 128mA = 告警线×4/5）。

## 3. 事件
与 04 相同事件集（overcurrent/recovered/comm_lost），固件暂未上送，按需补。

## 4. 示例完整帧

```json
{"ver":"1.0","type":"module.data","module":"ina226_u44","seq":40,"ts_ms":4200000,"data":{"cur_ma":103,"over_cur":0,"valid":1,"level":0}}
```

## 5. 后端解析要点
- 模块 id `ina226_u44` 与 `ina226_u10` 区分同型号两颗；后端勿用 cur_ma 阈值交叉告警，统一用各自帧的 `level`。
