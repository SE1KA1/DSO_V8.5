# 模块 3：SHT40-AD1B-R2 温湿度传感器（温度监测）

## 1. 硬件与用途

| 项 | 值 |
|---|---|
| 器件 | SHT40-AD1B-R2（I2C 温湿度） |
| I2C 7 位地址 | **0x44**（SDA=PB7, SCL=PB8，同一条软件 I2C 总线） |
| 固件 | dso_sht40.c：1s 采样任务（prio3），缓存温度 + 有效性 + 分级告警 |
| 用途 | 过桥板环境温度监测，参与声光联动（LED YDS3/YDS4 + 蜂鸣器，见 02 总则） |

当前仅上报温度（湿度字节已读取但未换算/未上报，需要时扩展）。

## 2. 周期上报 `type: module.data`（1s 周期）

```json
"data": {
  "temp_dezi": 245,     // int  温度，十分之一 ℃（245 = 24.5℃）
  "temp_ok": 1,         // int 0/1  传感器有效（连续失败>10 → 0）
  "hi_alarm": 0,        // int 0/1  温度 > 告警线(60.0℃) = level≥2
  "level": 0            // int  声光联动分级：0正常 1预警 2告警 3紧急（见下）
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `temp_dezi` | int | ✓ | 十分之一 ℃，范围约 -400..1250 |
| `temp_ok` | int | ✓ | 0/1；0 时后端应显示"不可用"而非数值 |
| `hi_alarm` | int | ✓ | 0/1；1=严格 >60℃（level≥2） |
| `level` | int | ✓ | 分级见下表；传感器无效时强制 0（防误报） |

**温度分级阈值**（宏见 `User/dso/dso_sht40.h`：WARN 5800 / ALARM_HI 6000 / EMERG 6500，centi℃）：
| level | 语义 | 阈值 | 硬件动作（按 02 总则） |
|---|---|---|---|
| 0 | 正常 | ≤58.0℃ | YDS3 蓝常亮；蜂鸣器静音 |
| 1 | 预警 | >58.0℃ | YDS4 橙慢闪 500ms/500ms；蜂鸣 250/1750ms |
| 2 | 告警 | >60.0℃ | YDS4 橙快闪 250ms/250ms；蜂鸣 250/250ms |
| 3 | 紧急 | >65.0℃ | YDS4 橙爆闪 100ms/100ms；蜂鸣 100/100ms |

> 蜂鸣器由固件节奏引擎统一驱动，**等级取温度与两路电流的最高档**（温度报警同样会响蜂鸣器，不再只有电流触发）；可被 `set_buzzer` 静音（LED 照常）。正常温度回落 ≤3 采样周期后自动静音。

## 3. 事件 `type: module.event`

```json
"data": {"event": "sensor_lost", "level": "warning", "detail": "temp_ok 0 after 10 fails"}
```

| event | 触发 |
|---|---|
| `sensor_lost` | `temp_ok` 由 1→0（连续读取失败超阈值） |

## 4. 示例完整帧

```json
{"ver":"1.0","type":"module.data","module":"sht40","seq":10,"ts_ms":1500000,"data":{"temp_dezi":245,"temp_ok":1,"hi_alarm":0,"level":0}}
{"ver":"1.0","type":"module.event","module":"sht40","seq":11,"ts_ms":1600500,"data":{"event":"sensor_lost","level":"warning","detail":"10 consecutive read fails"}}
```

## 5. 后端解析要点
- 用 `module=="sht40"` 分派；校验可用 `python_ref/module_sht40.py`。
- 与 GUI `get_switch` 通道的 `temp`/`temp_ok` 同源同值；本模块帧为独立周期推送，便于后端统一订阅。
- 温度告警状态给前端展示：直接用 `level`（比 hi_alarm 更细，区分预警/告警/紧急），温度数值用 `temp_dezi/10`。
