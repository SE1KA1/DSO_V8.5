## 二、LAN8720A 以太网 PHY

### 2.1 PHY 地址

**自动探测，非硬编码。** `LAN8742_Init()` 扫描地址 0-31，读取 SMR 寄存器 bit[4:0] 与扫描地址匹配。

实测串口输出: `dev=0x01` → **PHY 地址 = 0x01**

| 参数 | 值 |
|------|-----|
| PHY 型号 | LAN8720A（驱动兼容 LAN8742） |
| PHY 地址 | **0x01**（由外部 strap 电阻确定） |
| PHY 地址探测方式 | 扫描 0-31，匹配 SMR bit[4:0] |
| 探测文件 | `Drivers/BSP/Components/lan8742/lan8742.c:83-130` |

### 2.2 RMII 引脚映射（已验证）

| RMII 信号 | STM32 引脚 | GPIO_AF | GPIO 速度 | 状态 |
|-----------|-----------|---------|-----------|------|
| ETH_MDC | PC1 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_REF_CLK | PA1 | AF11_ETH | MEDIUM | ✅ 已验证 (50MHz, PHY→STM32) |
| ETH_MDIO | PA2 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_CRS_DV | PA7 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_RXD0 | PC4 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_RXD1 | PC5 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_TX_EN | PG11 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_TXD0 | PG13 | AF11_ETH | MEDIUM | ✅ 已验证 |
| ETH_TXD1 | PG14 | AF11_ETH | MEDIUM | ✅ 已验证 |

### 2.3 REF_CLK 方向

PA1 配置为 `ETH_REF_CLK`（AF11_ETH），时钟由 **LAN8720A PHY 输出 50MHz 到 STM32**。这是 RMII 标准时钟方案（PHY 提供 REF_CLK）。

### 2.4 PHY 复位

| 信号 | 引脚 | 说明 |
|------|------|------|
| PHY nRST | PI3 | 10ms 低电平 → 50ms 高电平脉冲复位 |
| 复位时机 | `ETH_PHY_IO_Init()` | 每次 ETH 初始化时执行 |
| 复位后稳定时间 | 1500ms | `LAN8720_PHY_RESET_SETTLE_MS` |

### 2.5 PHY 实测计划

| 测试项 | 方法 | 工具 |
|--------|------|------|
| PHY 地址 strap 电阻 | PI3/硬件配置 确认 LAN8720A MODE[2:0] strap | 查看原理图 |
| 50MHz REF_CLK 质量 | 示波器测 PA1，检查抖动/幅度 | 示波器 ≥200MHz |
| MDIO 通信 | 逻辑分析仪抓 PC1(MDC) + PA2(MDIO) | 逻辑分析仪 |
| PHY 寄存器 dump | 串口输出 PHY BCR/BSR/PHYSCSR（已有 `eth_dbg` 结构体） | 串口 |

## 三、云桥 60PIN 与 FPGA/MUX 控制信号

### 3.1 硬件架构

```
STM32H743IITx (CPU)
    │
    ├── SPI4 (PE2/PE4/PE5/PE6) ──→ LCMXO2-4000HC (桥接 FPGA)
    │                                    │
    │                                    └──→ XC7A100 (主 FPGA)
    │
    ├── FMC 总线 ──→ SDRAM + NAND Flash + HC574 IO 扩展器 (32 GPIO)
    │
    ├── ETH RMII ──→ LAN8720A PHY ──→ RJ45
    │
    ├── BTB_60PIN J1 ──→ FPGA 外扩 I/O
    │
    └── BTB_100PIN ──→ 外部扩展
```

## 四、三条物理数据路径

### 路径 A: 以太网数据路径

```
PC ←→ RJ45 ←→ LAN8720A ←→ RMII(PA1/PA2/PA7/PC1/PC4/PC5/PG11/PG13/PG14)
    ←→ STM32H7 ETH MAC ←→ DMA (0x30000000 SRAM1) ←→ LwIP 栈 ←→ TCP 5005
```
- **方向**: 双向
- **协议**: Ethernet / IP / TCP
- **PHY 地址**: 0x01
- **速率**: 100Mbps Full-Duplex
- **状态**: ✅ 已实现，ping/TCP 验证通过

### 路径 B: USB 数据路径（待实现）

```
PC (USB Host) ←→ USB 线缆 ←→ USB3300 ←→ ULPI(12线)
    ←→ STM32H7 OTG_HS ←→ USB CDC 设备栈
```
- **方向**: STM32 为 USB Device, PC 为 USB Host
- **协议**: USB 2.0 High-Speed / CDC ACM (虚拟串口)
- **PHY**: USB3300 (ULPI 接口)
- **时钟**: 60MHz ULPI CLK (PA5, STM32→PHY)
- **参考源码**: `ETH_STM32_FPGA-main/USB_DEVICE/`
- **状态**: ⚠️ 待移植实现

### 路径 C: FPGA/云端数据路径（待实现）

```
FPGA XC7A100 ←→ SPI4 ←→ STM32H7 ←→ ETH ←→ PC/云端
```
- **方向**: FPGA→STM32 上行(SPI4 MISO), STM32→PC 上行(TCP), PC→FPGA 下行
- **协议**: SPI4 多核通信 / TCP 透传
- **桥接**: LCMXO2-4000HC (SPI4 中继)
- **参考源码**: `ETH_STM32_FPGA-main/Core/Src/spi.c` + `Bsp/Bsp_ETH.c`
- **状态**: ⚠️ 待集成

```
FPGA XC7A100 ←→ BTB_60PIN J1 ←→ 外部 I/O (AD/DA/GPIO)
```
- **方向**: 双向
- **协议**: FPGA 自定义 I/O
- **状态**: ⚠️ 待实现
