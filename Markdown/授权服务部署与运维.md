# 授权服务：部署与运维

> 适用版本：2026-10-23（`tools/auth_server`，协议 v0 / Stage 2C）
> 关联文档：`Markdown/设备授权协议_v0.md`（格式与安全边界）

---

## 1. 启动 / 停止

```powershell
cd D:\DSO_V8.5
$PY = "C:\Users\GXKJ-TWO\AppData\Local\Programs\Python\Python312\python.exe"   # 需含 cryptography

# 启动（默认只监听 127.0.0.1:8080）
& $PY -m tools.auth_server.http_api --port 8080

# 指定状态目录（多套环境隔离时用）
& $PY -m tools.auth_server.http_api --port 8080 --state D:\auth-state
```

- **停止**：Ctrl+C。服务会写一条 `server_stop` 审计并删除锁文件。
- **单实例**：启动时独占 `.state/server.lock`。若进程被强杀留下锁文件，下次启动会按里面记录的
  PID 判断——进程已不在则自动接管；若 PID 仍存活则拒绝启动。
- **不要**用 `--unsafe-lan` 对外绑定，除非你已经接受"明文 HTTP、会话在局域网裸奔"。

## 2. `.state/` 目录（**必须备份**）

| 文件 | 内容 | 备份 | 说明 |
|---|---|---|---|
| `ca_key.pem` | **CA 私钥**（PKCS8，未加密） | **必须** | 丢了就再也签不出设备能认的 License |
| `store.json` | 用户（PBKDF2 哈希）、设备台账、绑定、已签发 License | 必须 | 整文件重写模型，建议停服备份 |
| `admin_token` | 管理端令牌（32 hex） | 建议 | 丢失可重新生成（旧令牌立即失效） |
| `audit.jsonl` / `.1` | 审计日志（当前 + 上一代） | 建议 | 超过 2 MB 自动轮转为 `.1` |
| `server.lock` | 单实例锁 | 不需要 | 停服即删 |

**迁移到另一台机器**：整个 `.state/` 目录拷过去即可（同一份 CA ⇒ 已发 License 继续有效）。
**迁移后**：`User/dso/dso_auth_ca.h` 里的 CA 公钥必须与之匹配（见 §4）。

## 3. 常用运维操作

| 目的 | CLI | HTTP |
|---|---|---|
| 建学生账号 | `service add-user stu001` | `POST /api/admin/users` |
| 登记设备 | `service register <ID> <pubkey> --host 192.168.100.50 --port 5005` | `POST /api/admin/devices` |
| 绑定（学生↔设备） | `service bind stu001 <ID> --days 30` | `POST /api/admin/bindings` |
| 改绑定期限 | `service bind … --force` | 同上 + `{"replace": true}` |
| 授权（学生） | `service flow --host <IP> --user stu001` | `POST /api/authorize` |
| 续期 | `service renew --host <IP> --user stu001` | `POST /api/authorize`（同义） |
| 查设备当前 License | `service license --host <IP>` | `GET /api/device/<ID>/license` |
| 吊销单张 | `service revoke --jti <jti>` | `POST /api/admin/revoke {"jti":…}` 或 `{"lic":"L00005"}` |
| 吊销整机 | `service revoke --device <ID>` | `POST /api/admin/revoke {"device":…}` |
| 学生授权历史 | — | `GET /api/history?limit=N`（只返回本人） |
| 审计 | — | `GET /api/admin/audit?limit=&event=&device=` |
| 审计导出 | — | `GET /api/admin/audit/export`（CSV） |

**服务运行中也能用 CLI 改台账**：服务每次请求前会按文件 mtime 重新加载 `store.json`。
避免"同一瞬间"两边同时写（整文件重写模型）。

**设备登记注意**：`host/port` 只能由管理员设置（CLI 或 `/api/admin/devices`），
API 绝不从学生请求里取地址——否则等于给了内网扫描接口。

## 4. CA 轮换

> 轮换后**所有旧 License 立刻失效**（设备端用新公钥验签），需要重新授权。

1. 停服，备份 `.state/`；
2. 删除或改名 `ca_key.pem`（新 CA 会在下次启动时生成）；
3. `python -m tools.auth_server.service show-ca --c > User/dso/dso_auth_ca.h`；
4. 重新编译并烧录固件（设备用新公钥验签）；
5. 启动服务，重新登记设备 / 绑定 / 授权。

## 5. 故障排查

| 现象 / `code` | 原因 | 处理 |
|---|---|---|
| `device_no_address` | 设备登记时没给 `--host` | 重新 `register … --host`（会覆盖） |
| `device_timeout`（504） | 设备未上电 / 被别的客户端占用 / 首次初始化太慢 | 确认设备在线、关掉 PC 面板；**先查询再重试**，别盲目重发 |
| `device_mismatch`（409） | 该地址上的设备 DeviceID 与请求不符 | 检查是否登记错设备/地址 |
| `no_binding`（403） | 学生与该设备没有有效绑定 | `bind`（或换学生） |
| `capability`（403） | 设备是 `identity_only`，不能发 FPGA 权限 | 见 §6 |
| `binding_exists`（409） | 同学生+同设备已有有效绑定 | 需要改期限时加 `--force` / `replace:true` |
| `license_unknown`（404） | 吊销时填的号不存在 | 在"License 台账"里选，别手抄 |
| `already_revoked`（409） | 重复吊销 | 无需处理 |
| `session_expired`（401） | 会话 30 分钟到期或服务重启 | 重新登录 |
| `locked`（429） | 同一账号 5 次密码错误，锁 5 分钟 | 等待或由管理员重置 |
| `admin_denied` / `admin_rate_limited` | 令牌错 / 失败 10 次/分钟 | 重新填 `.state/admin_token` |
| `421 bad_host` | 用 IP 或域名访问，不是 `127.0.0.1/localhost` | 用回环地址访问 |
| `403 cross_origin` | 从别的站点发起的请求 | 直接打开本机页面 |
| 页面 401 但 CLI 正常 | 浏览器里存的是旧令牌/旧 sid | 清 sessionStorage 后重试 |

## 6. 能力等级（`provisioned` / `identity_only`）

- **`provisioned`**：能完成设备证明（对服务器挑战签名）⇒ 可以签发 License（含 FPGA 权限）。
- **`identity_only`**：只能读设备号（`auth_start` 回 `st=0x0F`）⇒ **一张 License 都不发**，
  因为设备号可伪造，只有签名才证明"私钥在这台设备里"。

当前板子烧的是 Stage 2C 软件后端，因此判为 `provisioned`。**若关掉 `DSO_AUTH_DEV_SOFTKEY`
重新烧录**，ATECC 未锁定 ⇒ 会退回 `identity_only`，授权功能随之不可用。

## 7. 已知限制与设计决定

| 限制 | 说明 / 原因 |
|---|---|
| 明文 HTTP、仅回环 | 跨机访问需要 SSH 隧道（`ssh -L 8080:127.0.0.1:8080 …`）或另做白名单+TLS 评审 |
| 单进程 + JSON 台账 | 不支持多实例；扩展需换数据库与文件锁 |
| 设备无时钟 | License 的过期只能由服务器判定；设备侧只验签名与设备绑定 |
| License **可跨重启** | 授权成功后写入板载 **AT24C128（0x50，PB7/PB8 软件 I²C）**，重启后读回并**重新验签**；`restored=1` 表示恢复态。设备无时钟 ⇒ **不判过期**；服务器吊销**不会清除设备端记录**。详见协议 §10.5 |
| 未使用内部 Flash | 内部 Flash 需预留扇区，且 H7 双 bank 擦除会停顿同 bank 代码（授权路径/mbedTLS/`HAL_GetTick` 都在 bank 2）⇒ 选择外部 EEPROM |
| EEPROM 早期结论有误 | 旧文档称"AT24C128 用 PB9、与看门狗冲突"是**错的**：本板 EEPROM 在 **PB7/PB8**，与看门狗无关（已订正） |
| 设备侧只上报不拦截 | `login_state` 仅遥测；`set_sw`/FPGA 通道目前不因授权失败而关闭 |
| CA 私钥在本机文件 | 无 HSM；生产需替换 |
