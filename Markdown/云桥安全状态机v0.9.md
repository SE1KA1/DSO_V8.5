# 云桥安全状态机 v0.9

> 定义云桥系统全部 7 个运行状态、迁移条件、掉线回退策略和高危操作前置条件。

---

## 一、状态定义

```
                    ┌─────────┐
         上电/硬复位  │  SAFE   │←──────────────────────┐
              │      │ (默认)   │   连续3次E001/E003     │
              ▼      └────┬─────┘                        │
         ┌─────────┐      │ 健康检查通过                   │
         │  LOCAL  │      ▼                              │
         │(独立运行)│ ┌─────────┐   用户指令               │
         └────┬─────┘ │ CONFIG  │←────────┐              │
              │       │ (配置)   │         │              │
    ETH插入    │       └────┬─────┘         │              │
    PC连接     ▼            │ 配置完成       │              │
         ┌─────────┐        ▼               │              │
         │   PC    │   ┌──────────┐  云端连接│              │
         │(直连PC) │   │ RECOVERY │─────────┘              │
         └────┬─────┘   │ (恢复)   │ 云端断开               │
              │         └──────────┘                       │
    用户切换   ▼                                           │
         ┌─────────┐                                       │
         │  CLOUD  │                                       │
         │(连接云端)│                                       │
         └────┬─────┘                                       │
              │                                             │
              ▼                                             │
         ┌─────────┐                                       │
         │  DEBUG  │  (开发者模式)                           │
         └─────────┘                                       │
```

### 1.1 SAFE（安全模式）—— 上电默认态

| 属性 | 值 |
|------|-----|
| 进入条件 | 上电复位 / 硬复位 / 连续 3 次 OVR 或 ETH 断链 / 看门狗超时 |
| ETH 行为 | 仅发送遥测帧（单向），**拒绝所有控制指令** |
| ADC 行为 | 8-bit 模式，33.33MSPS，PC2 通道配置 |
| FPGA 行为 | 保持运行态，不重新配置 |
| AWG 行为 | 停止 |
| 串口 | 1152000 baud，输出状态和错误日志 |
| 退出条件 | 健康检查通过（无 OVR × 10s + ETH LINK UP × 5s）→ 自动进入 LOCAL |

**前置条件**: 无。SAFE 是所有状态的最终回退。

### 1.2 LOCAL（独立运行）

| 属性 | 值 |
|------|-----|
| 进入条件 | SAFE 健康检查通过 / 用户从 PC/CLOUD 主动断开 |
| ETH 行为 | 接受控制指令，发送遥测帧 |
| 交互方式 | 设备面板（EC11 编码器 + LCD）为**唯一控制入口** |
| PC 控制 | **不接受**（TCP 仅遥测输出） |
| 退出条件 | PC 连接成功 + 用户指令 → PC / 用户配置 → CONFIG |

**前置条件**: 健康检查通过。

### 1.3 PC（直连 PC 模式）

| 属性 | 值 |
|------|-----|
| 进入条件 | LOCAL 状态下，ETH 链路 UP + PC TCP 客户端连接 + 用户确认 |
| 控制权 | **PC 为优先控制端**，设备面板除 RUN/STOP 外锁定 |
| ETH 行为 | 双向——遥测帧推送 + 控制指令接收 |
| 退出条件 | TCP 断开 → 自动回退 LOCAL / 用户切换 → CLOUD / 异常 → SAFE |

**前置条件**:
- 当前状态 = LOCAL 或 CLOUD
- ETH LINK UP ≥ 3s
- TCP 客户端已连接

### 1.4 CLOUD（云端连接模式）

| 属性 | 值 |
|------|-----|
| 进入条件 | PC 状态下，云端服务器连接成功 + 用户确认 |
| 控制权 | 云端优先，PC 为备 |
| ETH 行为 | 双向——遥测帧推送 + 控制指令接收 |
| FPGA 上行 | 使能（FPGA 数据经 SPI4→STM32→ETH→云端） |
| 退出条件 | 云端断开 → 自动回退 PC / 用户指令 → PC / 异常 → SAFE |

**前置条件**:
- 当前状态 = PC
- 云端服务器 IP 已配置
- 云端连接测试通过（ping + TCP 握手）

### 1.5 DEBUG（开发者模式）

| 属性 | 值 |
|------|-----|
| 进入条件 | PC/CLOUD 状态下，用户发送 `set_state:DEBUG` + 确认码 |
| 串口 | 1152000 baud，全量寄存器 dump，原始 ADC 数据流 |
| ETH 行为 | 保持连接，但遥测帧增加调试字段（DMA 位置、TIM 寄存器） |
| ADC 行为 | 可切换模式（8-bit / 10-bit / 校准模式） |
| FPGA 行为 | 可通过 SPI4 发送调试指令 |
| 退出条件 | 用户指令 / 复位 → SAFE |

**前置条件**:
- 当前状态 = PC 或 CLOUD
- `set_state:DEBUG` 指令携带有效确认码（MD5 校验）
- 开发者已通过串口验证物理连接

### 1.6 CONFIG（配置模式）

| 属性 | 值 |
|------|-----|
| 进入条件 | LOCAL/PC 状态下，用户长按进入配置菜单 |
| ETH 行为 | 维持当前连接 |
| 可配置项 | 云端服务器 IP/端口、FPGA SPI4 速率、采集 profile、PHY 参数 |
| 退出条件 | 配置保存 → 返回进入前状态 / 配置放弃 → 返回进入前状态 |

**前置条件**: 当前状态 ≠ SAFE。

### 1.7 RECOVERY（恢复模式）

| 属性 | 值 |
|------|-----|
| 进入条件 | CONFIG 状态下请求 FPGA 重配置 / 固件更新 / 系统恢复 |
| ETH 行为 | 仅维持 TCP 连接，暂停遥测推送 |
| FPGA 行为 | 完整重配置流程（nCONFIG→CONF_DONE→DCLK→DATA0） |
| 退出条件 | FPGA 配置完成 + CONF_DONE=HIGH → SAFE / 超时 30s → SAFE |

**前置条件**:
- 当前状态 = CONFIG
- FPGA 位流文件已校验（CRC32）
- 用户二次确认（"YES" 字符串）

## 二、状态迁移矩阵

| 当前 → 目标 | SAFE | LOCAL | PC | CLOUD | DEBUG | CONFIG | RECOVERY |
|------------|------|-------|-----|-------|-------|--------|----------|
| **SAFE** | — | 自动 | ❌ | ❌ | ❌ | ❌ | ❌ |
| **LOCAL** | 异常 | — | 用户 | ❌ | ❌ | 用户 | ❌ |
| **PC** | 异常 | 断连 | — | 用户 | 用户+码 | 用户 | ❌ |
| **CLOUD** | 异常 | 断连 | 用户 | — | 用户+码 | 用户 | ❌ |
| **DEBUG** | 用户/异常 | ❌ | 复位 | 复位 | — | ❌ | ❌ |
| **CONFIG** | 异常 | 保存/放弃 | 保存/放弃 | 保存/放弃 | ❌ | — | 用户+确认 |
| **RECOVERY** | 完成/超时 | ❌ | ❌ | ❌ | ❌ | ❌ | — |

图例: `自动` = 条件触发自动迁移 / `用户` = 用户指令触发 / `异常` = 错误触发自动回退 / `❌` = 禁止直接迁移

## 三、上电默认态

| 项 | 默认值 |
|----|--------|
| 初始状态 | **SAFE** |
| 健康检查间隔 | 1s |
| 健康检查通过条件 | OVR 计数 10s 内无新增 + ETH LINK UP 持续 5s |
| SAFE→LOCAL 自动迁移 | 健康检查通过后立即执行 |

上电流程：
```
上电 → SAFE
  │
  ├─ 硬件自检 (~2s): MPU/时钟/D2 SRAM/ETH PHY 初始化
  │   失败 → 保持 SAFE，串口输出错误码
  │
  ├─ 健康检查 (最长 10s): 监控 OVR + ETH LINK
  │   通过 → 自动迁移到 LOCAL
  │
  └─ LOCAL: 正常示波器功能，等待连接
```

## 四、掉线回退策略

### 4.1 以太网断链（ETH LINK DOWN）

| 超时 | 动作 |
|------|------|
| < 5s | 缓存遥测帧（最多 50 帧 RAM），等待恢复 |
| 5-30s | 状态保持，串口告警，LCD 显示 "ETH_LINK_DOWN" |
| > 30s | 自动迁移到 **LOCAL**（若在 PC/CLOUD），停止缓存 |
| 连续 5 次断链/重连 | 自动迁移到 **SAFE** |

### 4.2 TCP 连接断开

| 原状态 | 动作 |
|--------|------|
| PC | 自动迁移到 **LOCAL**，3s 内重连成功则恢复 PC |
| CLOUD | 自动迁移到 **PC**，10s 内重连成功则恢复 CLOUD |
| DEBUG | 自动迁移到 **PC** |
| CONFIG | 保持 CONFIG，串口告警 |
| RECOVERY | 保持 RECOVERY（FPGA 编程不中断） |

### 4.3 FPGA SPI4 超时

| 超时 | 动作 |
|------|------|
| < 500ms | 重试 SPI4 通信 |
| 500ms-5s | 串口告警 E006 |
| > 5s | 若在 CLOUD/CONFIG/RECOVERY → 自动迁移到 **SAFE** |

### 4.4 连续错误回退

| 条件 | 动作 |
|------|------|
| OVR 连续 ≥ 3 次 | 自动迁移到 **SAFE** |
| ETH_LINK_DOWN 连续 ≥ 3 次 | 自动迁移到 **SAFE** |
| HEAP_LOW 触发 | 自动迁移到 **SAFE** |
| SAFE 状态持续 > 60s | 串口持续告警，建议硬复位 |

## 五、高危操作前置条件

| 操作 | 风险等级 | 前置条件 | 确认方式 |
|------|---------|---------|---------|
| 进入 RECOVERY | 🔴 极高 | CONFIG 状态 + FPGA 位流 CRC32 通过 | 二次确认 "YES" |
| FPGA 重配置 | 🔴 极高 | RECOVERY 状态 + nCONFIG 脉冲已就绪 | 自动 |
| 切换采集 profile | 🟡 中 | 不在 CLOUD/RECOVERY 状态 | 单次确认 |
| 关闭 SAFE 模式 | 🟡 中 | 健康检查通过 | 自动 |
| 固件 OTA 更新 | 🔴 极高 | RECOVERY 状态 + OTA 包签名验证通过 | 二次确认 |
| 擦除校准数据 | 🔴 极高 | CONFIG 状态 + 已备份当前校准 | 二次确认 |
| 修改云端服务器 IP | 🟡 中 | CONFIG 状态 | 单次确认 |
| 进入 DEBUG | 🟡 中 | PC/CLOUD 状态 + 确认码 | 确认码 |
| 切换 FPGA 位流 | 🔴 极高 | RECOVERY 状态 | 二次确认 |
| 禁用 ETH 回退 SAFE | 🟢 低 | DEBUG 状态 | 单次确认 |
