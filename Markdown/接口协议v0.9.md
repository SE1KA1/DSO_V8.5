# 接口协议 v0.9

> 云桥（Cloud Bridge）接口协议。DSO 固件端 ↔ PC/云端 数据通路规范。

---

## 一、物理层

| 通道 | 介质 | 拓扑 | 速率 | 方向 |
|------|------|------|------|------|
| A — 以太网 | RJ45 → LAN8720A → RMII | DSO ↔ PC 直连 | 100Mbps FD | 双向 |
| B — USB | USB 线缆 → USB3300 → ULPI | PC(Host) → DSO(Device) | 480Mbps HS | 双向 |
| C — FPGA 上行 | SPI4 (PE2/4/5/6) → LCMXO2 → XC7A100 | DSO 板内 | ~6.25Mbps | FPGA→STM32 |
| C — FPGA 下行 | TCP/JSON → DSO → SPI4 → FPGA | DSO → FPGA | — | STM32→FPGA |

**默认激活通道**: A（以太网 TCP 5005）。B/C 通道根据系统状态按需激活。

### 2.1 传输层
- 协议：TCP
- 端口：5005
- 编码：UTF-8 JSON，每条消息以 `\r\n` 结尾
- 推送频率：每帧采集完成时推送，或空闲时每 500ms 推送心跳

## 三、控制指令协议（PC/Cloud → DSO）

### 3.1 传输层
- 协议：TCP，同一条连接（端口 5005）
- 编码：UTF-8 JSON，每条以 `\r\n` 结尾
- 响应：DSO 在下一遥测帧中反映新参数值

### 3.2 指令格式

```json
{
  "ver": "0.9",
  "cmd": "set_trig_mode",
  "seq": 100,
  "params": { "mode": 1 }
}
```

### 3.3 指令表

| cmd | params | 说明 | 前置条件 |
|-----|--------|------|---------|
| `set_trig_mode` | `mode` (0=Auto,1=Norm,2=Single) | 设置触发模式 | 不限 |
| `set_trig_slope` | `slope` (0=Rise,1=Fall,2=Both) | 设置触发边沿 | 不限 |
| `set_trig_source` | `source` (0=CH1,1=CH2) | 设置触发源 | 不限 |
| `set_trig_level` | `level_v` (float) | 设置触发电平 | 不限 |
| `set_trig_pos` | `pos_pct` (0-100) | 设置触发位置 | 不限 |
| `set_run` | `running` (bool) | RUN/STOP | 不在 RECOVERY/SAFE |
| `set_ch_coupling` | `ch` (0/1), `coupling` (0=DC,1=AC,2=GND) | 设置耦合 | 不限 |
| `set_ch_probe` | `ch` (0/1), `probe` (1/10) | 设置探头倍率 | 不限 |
| `set_ch_offset` | `ch` (0/1), `offset_v` (float) | 设置垂直偏移 | 不限 |
| `set_ch_vdiv` | `ch` (0/1), `vdiv_index` (int) | 设置垂直档位 | 不限 |
| `set_acq_mode` | `mode` (0=Sample,1=Peak,2=HiRes,3=Avg) | 设置采集模式 | 不在 SAFE |
| `set_awg_start` | (none) | 启动 AWG | 不在 SAFE |
| `set_awg_stop` | (none) | 停止 AWG | 不限 |
| `set_awg_wave` | `wave` (0=Sine,1=Tri,2=Sqr) | 设置 AWG 波形 | 不限 |
| `set_awg_hz` | `hz` (int) | 设置 AWG 频率 | 需有效 profile |
| `set_state` | `target` (str) | 请求状态切换 | 见状态机前置条件 |
| `get_config` | `section` (str) | 读取当前系统配置 | 不限 |
| `reboot` | (none) | 软复位 DSO | **CONFIG / RECOVERY 状态** |

### 3.4 响应帧

```json
{
  "ver": "0.9",
  "type": "ack",
  "seq": 100,
  "cmd": "set_trig_mode",
  "result": "ok",
  "error": ""
}
```

## 四、MUX 真值表

DSO 内部信号路由由三个维度控制：系统状态、通道配置、FPGA 开关。

### 4.1 模拟输入 MUX（DSO 板内）

| 状态 | CH1 ADC1/2 输入 | CH1 ADC3 输入 | CH2 输入 | 说明 |
|------|----------------|---------------|---------|------|
| 默认 (8-bit) | PA6 (ADC12_INP3) | **PC2** (ADC3_INP0) | 不可用 | 三交织，ETH 降噪后配置 |
| 10-bit | PA6 | PA0 (ADC3_INP0) | **PC2** (ADC12_INP12) | 双通道模式 |
| SAFE | PA6 | PC2 | 不可用 | 回退到已验证配置 |

### 4.2 数字通信 MUX

| 状态 | 数据上行路径 | 数据下行路径 | 桥接 FPGA |
|------|------------|------------|----------|
| LOCAL | ETH → TCP 5005 → PC | PC → TCP 5005 → ETH | 不经过 |
| PC | ETH → TCP 5005 → PC | PC → TCP 5005 → ETH | 不经过 |
| CLOUD | ETH → TCP 5005 → PC → 云端 | 云端 → PC → TCP 5005 → ETH | 不经过 |
| DEBUG | UART1 (1152000 baud) | UART1 | 不经过 |
| CONFIG | SPI4 → STM32 → TCP | TCP → STM32 → SPI4 | **经过** LCMXO2→XC7A100 |
| RECOVERY | UART1 + SPI4 | UART1 + SPI4 | **经过** |
| SAFE | ETH 只发不收 | 不接受控制指令 | 不经过 |

### 4.3 FPGA 配置 MUX

| 操作 | nCONFIG(PC6) | CONF_DONE(PC13) | DCLK(PG12) | DATA0(PI8) | nRST |
|------|-------------|-----------------|------------|------------|------|
| 上电默认 | HIGH | 等待上升沿 | IDLE | 高阻 | HIGH |
| FPGA 编程 | LOW→HIGH (脉冲) | 监控 | 时钟输出 | 数据输出 | HIGH |
| FPGA 运行 | HIGH | HIGH | IDLE | 高阻 | HIGH |
| FPGA 复位 | HIGH | — | IDLE | — | LOW |

## 五、错误码表

| 错误码 | 名称 | 说明 | 触发条件 | 恢复动作 |
|--------|------|------|---------|---------|
| E001 | OVR | ADC DMA 溢出 | 采样率过高或 CPU 负载过大 | 降低采样率 |
| E002 | PHASE_SYNC | Lane 间相位同步丢失 | TIM1 CC 相位漂移 | 重新校准 |
| E003 | ETH_LINK_DOWN | 以太网链路断开 | 网线拔出或 PHY 异常 | 重新插拔网线 |
| E004 | TCP_DISCONNECT | TCP 客户端断开 | PC 端关闭连接 | 等待重连 |
| E005 | HEAP_LOW | FreeRTOS 堆不足 | 任务栈/队列分配失败 | 减少功能或增大堆 |
| E006 | FPGA_NO_RESP | FPGA SPI4 无响应 | FPGA 未配置或时钟异常 | 重新配置 FPGA |
| E007 | CAL_FAIL | 校准失败 | 无输入信号或信号异常 | 检查输入信号 |
| E008 | AWG_UNDERRUN | AWG DMA 欠载 | DAC 更新率超限 | 降低 AWG 频率 |
| E009 | SAFE_TRIGGERED | 安全模式触发 | 连续 3 次以上 E001 或 E003 | 自动进入 SAFE |
