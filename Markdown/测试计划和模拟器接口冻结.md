## 三、模拟器接口冻结

### 3.1 模拟器用途

`cloud_bridge_simulator.py` —— 纯 Python 实现的 PC 端测试工具，用于：

1. 模拟 TCP 客户端（接收遥测帧 + 发送控制指令）
2. 验证 JSON 协议合规性
3. 自动化回归测试（CI 集成）
4. 开发阶段无需真实 DSO 硬件即可测试 PC 客户端代码

### 3.2 冻结 API

```python
class CloudBridgeSimulator:
    """
    云桥模拟器。接口在此版本冻结，后续不改变签名。
    Version: 0.9
    """

    # ---- 生命周期 ----
    def __init__(self, host: str = "192.168.100.50", port: int = 5005):
        """连接到 DSO。若不传参数，使用默认直连 IP。"""

    def connect(self) -> bool:
        """建立 TCP 连接。返回是否成功。"""

    def disconnect(self):
        """关闭 TCP 连接。"""

    def is_connected(self) -> bool:
        """返回当前连接状态。"""

    # ---- 遥测接收 ----
    def read_frame(self, timeout_ms: float = 1000.0) -> dict | None:
        """阻塞读取一帧遥测 JSON。超时返回 None。"""

    def read_frames(self, count: int, timeout_ms: float = 5000.0) -> list[dict]:
        """读取指定数量的遥测帧。超时返回已读到的帧列表。"""

    # ---- 控制发送 ----
    def send_cmd(self, cmd: str, params: dict | None = None) -> dict:
        """发送控制指令。返回 ack 帧。"""

    def set_trig_mode(self, mode: int): ...
    def set_trig_level(self, level_v: float): ...
    def set_run(self, running: bool): ...
    def set_ch_coupling(self, ch: int, coupling: int): ...
    def set_ch_vdiv(self, ch: int, vdiv_index: int): ...
    def set_state(self, target: str): ...

    # ---- 状态查询 ----
    def get_state(self) -> str:
        """从最近一帧中提取当前系统状态。"""

    # ---- 自动化测试 ----
    def verify_frame_schema(self, frame: dict) -> list[str]:
        """验证遥测帧 JSON schema。返回缺失/错误字段列表。"""

    def wait_for_state(self, state: str, timeout_ms: float = 10000.0) -> bool:
        """等待系统迁移到指定状态。超时返回 False。"""
```

### 3.3 模拟器 CLI

```bash
# 交互模式：连接 DSO 并显示实时波形数据
python cloud_bridge_simulator.py --interactive

# 自动化测试：运行全部单元测试
python cloud_bridge_simulator.py --test-all

# 单一测试
python cloud_bridge_simulator.py --test state_machine

# 录制模式：保存遥测帧到文件
python cloud_bridge_simulator.py --record output.jsonl

# 回放模式：从文件读取并模拟 DSO
python cloud_bridge_simulator.py --replay input.jsonl --serve
```

### 3.4 回放模式协议

回放模式下，模拟器作为 TCP 服务端运行（`--serve`），向连接的客户端发送录制的遥测帧，并接受控制指令（静默忽略或按录制轨迹响应）。此模式用于 PC 客户端开发时无需真实 DSO 硬件。

```
录制文件格式 (JSONL):
{"seq":1, "ts":1000, ...}
{"seq":2, "ts":1050, ...}
...
```

## 五、冻结声明

以下接口自 v0.9 起冻结，后续版本只做加法（新增字段/指令），不改变现有字段名称、类型、顺序或语义：

1. **遥测帧 JSON schema** (`ver: "0.9"` 版本号锁定)
2. **控制指令 JSON schema** (`cmd` + `params` 结构)
3. **TCP 端口** (5005)
4. **模拟器 Python API** (上述全部公开方法签名)
5. **状态机 7 状态定义** (SAFE/LOCAL/PC/CLOUD/DEBUG/CONFIG/RECOVERY)
6. **MUX 真值表** (模拟输入 + 数字通信 + FPGA 配置)
