# 波形绘制方案说明

> Historical note: 本文记录早期 PlotBuf/旋转优化阶段，部分尺寸和性能数据已经不再代表当前实现；当前实现以 `User/ui/dma2d_wave.h` 和 `docs/architecture/05-ui-display-and-input.md` 为准。

## 一、整体数据流（PlotBuf 模式）

ADC 或队列数据先写入 waveformData，再由 DrawWaveformsToBuf 按竖屏坐标画到 PlotBuf。PlotBuf 由 DMA2D 整块拷贝到物理缓冲的 plot 区。Header 由 emWin 画到逻辑缓冲，经 CPU 旋转到物理缓冲。物理缓冲由 LTDC 扫描输出到屏幕。

---

## 二、填色（背景恢复）

初始化时，DMA2D_PlotBuf_Init 用 CPU 循环填充 s_bg_buf 背景色，并画出网格和 CH1/CH2 标签。s_bg_buf 为 395×772 竖屏，内容固定。

每帧开始时，do_restore_bg 用 DMA2D M2M 把 s_bg_buf 拷贝到当前 s_plot_buf，恢复上一帧背景。该恢复在 DMA2D_PlotBuf_EndFrame 中异步启动，与 ManualRotate 并行，不阻塞主循环。

s_plot_buf 使用双缓冲 [0]/[1] 交替，每帧切换。

---

## 三、波形绘制

DrawWaveformsToBuf 遍历 waveformData：幅度 phys_x=PLOT_H-1-amp；时间 phys_y 由 `LCD_PLOTBUF_PHYS_Y_FROM_PX(px)`（CCW 默认 `LCD_PLOTBUF_CCW_MIRROR_TIME_Y=1` 即 PLOT_BUF_H-1-px，与 Init 网格一致）。仅接缝/边界线异常时不要关该镜像（会整块波形时间反了）；可试 `LCD_PLOTBUF_CCW_SEAM_FIX=1` 或微调 LCDConf 中 CCW 的 PHYS_PLOT。

**CCW 下 DMA2D 目标 `PHYS_PLOT_Y`** 基准为 `800 - ROTATE_PLOT_X - ROTATE_PLOT_W`（与 `phys_y = 799 - lx` 对齐），再加 `PHYS_PLOT_NUDGE_Y_CCW`（默认 -3）：负值使整块 plot 向时间结束侧（波形消失端、竖屏靠上）平移少许。勿过大以免与边距接缝。

draw_line：`USE_DMA2D_WAVEFORM_DRAW`（`dma2d_wave.h`，默认 1）为 1 时，Bresenham 仅用于走线，**同行连续像素合并为水平段**、**同列连续像素合并为竖段**，用 **DMA2D R2M**（`dma2d_fill_hline` / `dma2d_fill_vline`）写入 `s_plot_buf`，波形线段基本不占 CPU 填像素。设为 0 则斜线退回逐像素 CPU Bresenham；水平/竖直段仍可用打包写或简单循环。

---

## 四、旋转与搬运

ManualRotateToPhysical 负责把逻辑缓冲内容转到物理缓冲并切换显示。

首 2 帧做整屏 CPU 旋转，保证两个物理缓冲都有完整画面。

后续帧分两种处理。PlotBuf 就绪时，`ROTATE_BODY` 为 Header 以下整带。**`USE_ROTATE_BODY_STATIC_SKIP`（默认 1）**：仅首次进入 PlotBuf 分支 CPU 旋转 Body，之后靠拷屏继承边距。**`USE_ROTATE_HEADER_STATIC_SKIP`（默认 1，`lcd_rotate_request.h`）**：Header 仅**首帧进入 PlotBuf**或调用 **`LCDConf_RequestHeaderRotate()`** 后下一帧才 CPU 旋转；`MainTask` 内状态条（Roll/Y-T、RUN/STOP、档位、`[GUI]`）仅在内容变化时重绘并 `LCDConf_RequestHeaderRotate()`。若在别处改 Header 区像素，须自行调用该函数。波形仍由 DMA2D 贴 PlotBuf。`ROTATE_BODY_Y` 须等于 `ROTATE_HEADER_Y+ROTATE_HEADER_H`。

**须每帧**用 `CLR_BG_PLOT` 填充逻辑 plot 外框范围（与 `DrawGridFull` 双层框一致，含 ±2），再 `DrawYAxisTicks`，抹掉 init 留在逻辑缓冲上的网格/边框；否则 `ROTATE_BODY` 会旋出与 PlotBuf 重复的一套网格，在接缝或时间轴尽头旁出现「多一段线」。

---

## 五、显示

物理缓冲由 LTDC 扫描输出。ManualRotateToPhysical 在切换前更新 LTDC 的 CFBAR 指向新缓冲，等待 VSYNC 消隐期完成切换。物理缓冲采用 Ping-Pong 双缓冲，交替显示。

---

## 六、当前配置

USE_DMA2D_PLOTBUF 为 1，表示启用 PlotBuf 模式。USE_DMA2D_WAVEFORM_DRAW 为 1（默认）时波形线段由 DMA2D R2M 填 PlotBuf。WAVEFORM_STRIDE 为 2，每 2 个采样点画一条线段。

---

## 七、DMA2D 使用汇总

DMA2D 用途：背景恢复（s_bg_buf→s_plot_buf）、PlotBuf 到物理 plot 区、整屏 front/back 复制；在 `USE_DMA2D_WAVEFORM_DRAW=1` 时还用于 **波形线段 R2M**（水平/竖直段）。与 `ManualRotate`、背景恢复共用同一 DMA2D，各路径内已 `while (START)` 互斥。

---

## 八、GUI 回退模式（USE_DMA2D_PLOTBUF=0）

当 PlotBuf 未就绪或禁用时，使用 emWin 绘制。填色用 GUI_FillRect，网格用 GUI_DrawVLine 和 GUI_DrawHLine，波形用 GUI_DrawLine，全部画到逻辑缓冲。ManualRotateToPhysical 对 header 和 plot 做整屏 CPU 旋转到物理缓冲。

---

## 九、MainTask 帧率上限（≤60Hz）

`User/ui/MainTask.c` 中 **RUN** 时在每帧末尾 `vTaskDelayUntil`，周期 **`MAINTASK_FRAME_PERIOD_MS`（默认 17ms）**：RTOS tick 为 1ms 时约 **59fps**，避免 16ms 略超 60Hz。单帧处理已超过该周期时不额外拖延。STOP 仍为前置 **50ms** 延时；可在编译选项里 `-DMAINTASK_FRAME_PERIOD_MS=20` 等覆盖宏。

---

## 十、MainTask 分段耗时（测哪一环占 CPU）

在 `User/ui/profile_opts.h` 中 **`MAINTASK_PROFILE_EMWIN_SEGMENTS` 为 1**（须 `RTOS_CPU_STATS` + TIM6）。每约 50 帧打印 `[0]…[7]`（`MAINTASK_PROFILE_ACCUM_FRAMES`，可在 `MainTask_profile.h` 改）。`[6]` 为整段 `ManualRotateToPhysical`；其下 **`[6a]`** = 写 CFBAR 之前（DMA/Cache/旋转等），**`[6b]`** = VSYNC `while`+`vTaskDelay` 墙钟。再下 **`[6a0]…[6a7]`** 为 [6a] 内分阶段（PlotBuf 稳态常见：`6a0` 整屏物理 M2M，`6a1` DCache，`6a2/3` Header/Body 旋转，`6a4` Plot M2M；首两帧见 `6a5`；关 `USE_PARTIAL_ROTATE` 见 `6a7`）。`LCDConf` 与 `MainTask` 须共用 `profile_opts.h`（勿只在 `MainTask.c` 里 `#define`）。实现：`MainTask_profile.h`、`lcd_rotate_profile.c`、`lcd_rotate_profile.h`。
