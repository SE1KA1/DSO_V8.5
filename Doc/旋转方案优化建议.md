# 旋转方案优化建议

屏幕物理为 480×800 竖屏，不支持横屏。当前：逻辑 800×480 横屏绘制 + CPU 90° 旋转到物理竖屏。

---

## 一、当前架构与瓶颈

| 环节 | 实现 | 耗时/成本 |
|------|------|-----------|
| emWin 绘制 | 逻辑 800×480 | 视内容而定 |
| 波形 PlotBuf | 772×405 位图，DMA2D 恢复 + CPU 画线 | 已优化 |
| 旋转 | 32×32 分块，header(800×66) + plot(772×405) | ~3–4 ms 整屏 |
| DMA2D 复制 | 每帧整屏 front→back（480×800） | ~1–2 ms |
| VSYNC 等待 | vTaskDelay(1) 轮询 | ~19 ms/帧 |

**USE_PARTIAL_ROTATE=1** 时：首 2 帧整屏旋转，后续帧仅旋转 header + plot，其余由 DMA2D 整屏复制。

---

## 二、优化方向（按优先级）

### 1. 短期：在现有架构上微调

| 措施 | 说明 | 预期收益 |
|------|------|----------|
| **STOP 时降频** | 已实现：`vTaskDelay(50)` | 减少 STOP 时 CPU 空转 |
| **STOP 时跳过旋转** | 若 STOP 且无 UI 变化，可跳过 ManualRotate | 进一步省 CPU |
| **缩小 header 旋转区** | 若 header 实际变化区域更小，可缩小 ROTATE_HEADER_H | 略减旋转量 |
| **64×64 块** | 将 `ROTATE_BLOCK` 从 32 改为 64 | 可能略减少循环次数，视 Cache 情况而定 |

### 2. 中期：emWin 内置 ROTATION_CW（方案 A）

**目标**：emWin 直接写入物理竖屏缓冲，省去整块 CPU 旋转。

**步骤**：
1. `ORIENTATION_0` 改为 `ROTATION_CW`
2. `_aAddr` 指向物理缓冲（如 `VRAM_PHYSICAL_0`）
3. `LCD_SetSizeEx(0, 480, 800)`（物理尺寸）
4. 双缓冲：VSYNC 时切换 emWin 的 VRAM 地址，或沿用现有多缓冲机制

**风险**：STemWin OSX 驱动与 DMA2D FillRect、CopyBuffer 等配合需实测；可能需调整 `LCD_DMA2D_GetDrawBufBase` 等。

**建议**：先做小分支验证，确认无错行、颜色、撕裂后再合并。

### 3. 中期：绘制层直接竖屏

**目标**：PlotBuf 直接输出 480×800 竖屏布局，省去 plot 区域旋转。

**思路**：
- PlotBuf 改为 480×800 竖屏布局（或 405×772 竖屏 plot 区）
- 绘制时做坐标映射：逻辑横屏 (x,y) → 物理竖屏 (479-y, x)
- 仅 header 仍需旋转（或 header 也改为竖屏布局）

**工作量**：需改 `dma2d_wave.c` 坐标、`DrawWaveformsToBuf`、网格线等，中等。

### 4. DMA2D 能否做 90° 旋转？

**结论**：不能。

- DMA2D 支持 M2M：源/目标 stride 可不同，但仍是矩形拷贝
- 90° 旋转需要像素重排：`dst[479-y][x] = src[y][x]`，DMA2D 无法实现

---

## 三、推荐实施顺序

1. **已做**：STOP 时降频
2. **可选**：STOP 时若无 UI 变化，跳过整帧（含 ManualRotate）——需判断 `UI_Waveform_IsRunning()` 且无档位/模式变化
3. **验证**：emWin ROTATION_CW 方案，在独立分支测试
4. **若需进一步优化**：再考虑 PlotBuf 直接竖屏绘制

---

## 四、STOP 时跳过旋转（可选实现）

若 STOP 且 header 无变化（档位、模式未变），可跳过整帧：

```c
/* STOP 时：若无 UI 变化则跳过重绘+旋转 */
if (!UI_Waveform_IsRunning()) {
    static uint32_t last_scale_hash = 0;
    uint32_t h = UI_Waveform_GetScaleHash();  /* 需提供：档位/模式变化时变化 */
    if (h == last_scale_hash) {
        vTaskDelay(pdMS_TO_TICKS(100));
        continue;  /* 跳过本帧 */
    }
    last_scale_hash = h;
}
```

需在 `UI_WaveformCtrl` 中提供 `GetScaleHash()`，在档位/模式变化时变化。
